# StreamFlix IPTV — Samsung Smart TV (Tizen OS)

تطبيق مستقل تماماً لتلفزيونات **Samsung Smart TV (Tizen)** بنفس تجربة **Netflix** وبمشغل الهاردوير الأصلي **`AVPlay`** للتلفزيون:

* دخول بحساب **Xtream Codes** (`Host` + `Username` + `Password`) مع حفظ البروفايلات.
* تقليب القنوات المباشرة بأزرار **CH+ / CH-** على ريموت سامسونج.
* تقديم وترجيع فوري (`-10s` / `+10s`) بأسهم الريموت، وإيقاف/تشغيل بضغطة واحدة مع علامة **PAUSED**.
* استكمال المشاهدة (**Continue Watching**) بدقة الثانية + المفضلة (**My List**) + نظام الحماية من النوم (**Are you still watching?**).

## طريقة التثبيت على تلفزيون سامسونج
1. حمّل وثبّت **Tizen Studio** على الماك (واختر **TV Extensions** أثناء التثبيت).
2. على **تلفزيون سامسونج**:
   * افتح **Apps** ← اضغط بالأرقام على الريموت **`1 2 3 4 5`**.
   * فعّل **Developer Mode** على **ON** ← اكتب **IP جهاز الماك** ← أعد تشغيل التلفزيون.
3. في **Tizen Studio**:
   * افتح هذا المجلد (**File > Import > Tizen Project**).
   * من **Device Manager** وصّل بالتلفزيون بـ IP التلفزيون.
   * اضغط كليك يمين على المشروع ← **Run As > Tizen Web Application** — هينزل التطبيق على التلفزيون فوراً!
